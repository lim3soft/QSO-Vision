# QSO Vision build artifacts

These APKs are the historical binaries retained in the Codex workspace. They
are uploaded as artifacts only; the original v1.0, v1.1, and v1.2 source
snapshots were not retained and are not recreated as false source history.

| File | Historical reference |
|---|---|
| `QSO-Vision-before-1.3.apk` | Pre-1.3 retained build |
| `QSO-Vision-1.3.apk` | 1.3 retained build |
| `QSO-Vision-1.3.1.apk` | 1.3.1 retained build |
| `QSO-Vision-1.3.2a-build6.apk` | Latest source build, version 1.3.2a / code 6 |
| `QSO-Vision-1.3.3-build7.apk` | Responsive scaling and DOM-resilient metadata build |

The experimental GeckoView APK is intentionally not included because its
size exceeds GitHub's regular file limit and GeckoView was later removed.
